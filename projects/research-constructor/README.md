# Конструктор исследования

Интерактивная рабочая среда для проектирования психологического исследования: от исследовательского вопроса до выборки, методов, анализа, этики и аудита связности.

## Возможности

- паспорт и логическая карта проекта;
- выбор дизайна и границ допустимых выводов;
- конструктор выборки и ориентир её объёма;
- банк методик с оценкой нагрузки участника;
- шпаргалка выбора основного анализа;
- этический чек-лист и черновик информированного согласия;
- локальное автосохранение, JSON-резервная копия и экспорт в DOCX;
- аудит по 14 контрольным точкам.

## Запуск

```bash
npm install
npm run dev
```

Проверка: `npm run lint`, `npm test`. Для стандартной Next.js-сборки: `npx next build`.

Проект не предназначен для хранения персональных данных участников и не заменяет требования кафедры, консультацию научного руководителя или решение этического комитета.
